    Programs and programming languages

    A program is a set of instructions in a programming language for a computer to execute. Languages come in two styles. Sort each snippet: does it say how to do it step by step, or only what result it wants?

    0 / 6 sortedImperative = how · Declarative = what

    Key words from the slides

    ProgramA sequence of instructions, written in a programming language, for a computer to execute. One component of software.
    Programming languageA language used to write programs. Thousands exist: C++, C#, Visual Basic, Java …
    Source codeThe program in its human-readable form, such as Form1.cs.
    Executable (.exe)A file Windows can run: an application or an installer.

    Architecture of the .NET Framework

    .NET uses both ideas. A compiler turns C# into CIL stored in an assembly; when the app runs, the CLR's JIT compiler turns CIL into machine code. Click any block, or follow HelloWorld.exe through the layers.
